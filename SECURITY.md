# Security Policy

## Reporting

Do not publish credentials, production addresses, private player records or exploitable server details in a public issue. Contact the maintainer through the repository's published email or Telegram account and provide a minimal reproduction without personal data.

## Public repository scope

This repository contains source fragments, protocol resources and screenshots. Before using related code in a deployed service, review authentication, authorization, transport encryption, secrets handling, logging, rate limits, dependency versions and game-state validation.
