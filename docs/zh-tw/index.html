02

Texas Hold’em 基本玩法

  1. 01

    發放底牌

    每位玩家獲得兩張僅自己可見的底牌。

  2. 02

    翻牌與下注

    翻牌圈公開三張公共牌，各輪可跟注、加注或棄牌。

  3. 03

    轉牌與河牌

    隨後各公開一張公共牌，並繼續進行下注輪次。

  4. 04

    比較五張牌型

    從七張可用牌中組合最佳五張牌，決定底池歸屬。

05

常見問題

倉庫能否直接編譯部署？

目前公開檔案不足以組成完整可建置平台，需要補齊依賴、入口、資料庫、設定和客戶端工程。

是否包含完整撲克引擎？

頁面只描述實際可核驗的回呼與協議資源，不把缺少實作的內容聲明為完整引擎。

截圖是否證明全部功能已開源？

截圖證明相應介面存在，具體業務邏輯是否公開仍應逐項核對倉庫檔案。
